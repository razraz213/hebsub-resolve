# glossary.txt -- hebsub
#
# Built from measured ASR errors against a hand-corrected reference set.
# Judaica vocabulary; replace it with your own domain's terms.
# Format is D11: `wrong => right` for exact replacement, bare terms
# for fuzzy protection (>= 0.82 similarity, tokens of length >= 3).
#
# ONLY entries whose left-hand side is not a normal Hebrew word are
# listed. Of the 33 one-to-one errors measured, most were contextual
# -- the ASR heard a real word, just the wrong one. Those are at the
# bottom of this file, commented out, with the reason. Do not
# uncomment them: a deterministic rule that rewrites every 'כל' to
# 'קול' breaks far more than it fixes.
#
# Multi-word garble -- 'קידשנו במצוותיו' heard as 'כדשהם לצוטר' --
# is also excluded: collapsing it would change word count and break
# the timing contract (D31).
